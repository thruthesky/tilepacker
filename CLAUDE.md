Good news — there are several tools for exactly this. One important distinction first, since it determines which tool you want:
Tiled's standard image-based tileset expects a uniform grid (every tile the same cell size, optional margin/spacing). So you want a packer that lays tiles out on a fixed grid, not a tight "texture atlas" packer that rotates/trims/varies sizes. Tools in the latter category produce atlases that won't load as a normal Tiled tileset (you'd need collection-of-images mode or a custom loader instead).
Grid tileset packers (best fit for Tiled)
mini2dx/tilepacker — probably the closest match to what you're describing. A Gradle plugin and command-line utility for packing individual tile images into tilesets. You give it a config with tileWidth/tileHeight, tilesetWidth/tilesetHeight, and a list of tile images. It also supports tile padding and a "preventTearing" option that pads each tile by its border pixels to avoid bleeding when scaling. Free, CLI-driven — ideal for scripting into a build pipeline. githubgithub
TilePacker (craftworkgames) — a minimal cross-platform .NET tool. It packs a directory of PNG files into a single PNG texture, with each tile sized to the largest input image. Very basic but free and scriptable if you just need loose PNGs merged into one sheet. GitHub
TileFusion (itch.io, free) — a GUI option if you'd rather click than script. It's a simple tool to combine tiles and export them as a single PNG, letting you load a tileset, select and position individual tiles, and export the composition. It supports 8×8 up to 64×64 tiles on grids up to 16×16. The catch: PNG export only and Windows-only. itchitch
Tilesetter (~$12.99) — more than a packer; it's a tileset generator. It creates complete "smart" tilesets from a base image and auto-composites/updates the whole tileset based on various parameters. Worth it if you also want auto-tiling (edges/corners) rather than just packing existing tiles. Windows/macOS/Linux. Tilesetter
Texture-atlas packers (only if you're doing collection-of-images or a runtime atlas)
TexturePacker (CodeAndWeb) — the industry standard, has a free mode. Great for tight-packed atlases, but its default trim/rotate behavior breaks Tiled's uniform-grid assumption, so use it only for collection-of-images workflows or when your engine resolves regions by name.
tiny_packer (GitHub, free) — a CLI atlas tool. It combines multiple images into a single atlas with manual or automatic sizing and padding, and has a --unified flag that makes every cell the same size based on the largest image — that unified flag is what makes it usable for grid-style output. github
ImageMagick montage — the zero-dependency DIY route. montage *.png -tile 8x -geometry +0+0 -background none tileset.png packs a folder into a uniform grid in one command. Fits your scripting-heavy style.
For your Flame setup specifically
Since you're on flame_tiled, the grid packers (mini2dx/tilepacker or even the ImageMagick one-liner) are the cleanest path — they produce a sheet you point a .tsx at directly, no custom loader needed. If you want auto-tile variations generated for you, Tilesetter is the one that goes beyond pure packing.
